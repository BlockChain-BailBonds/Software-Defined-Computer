# Dependency and third-party review

The code contains project dependencies and platform integrations including FastAPI, Pydantic, pytest, httpx, SQLite, Node.js, llama.cpp-compatible server APIs, PlatformIO, ESP-IDF, firmware libraries and an external experimental ESP32-S3 Linux source. An API call or mention is not evidence that all upstream code is included in the repository.

**Before redistribution as a product:** inventory all distributed dependency versions and transitive dependencies, verify each authoritative license, include required notices, identify GPL/LGPL/copyleft obligations (especially if redistributing a Linux kernel or userspace), determine the provenance and legal status of AI-generated and imported code, and check any source trees incorporated under a prior agreement. Firmware generated by ESP-IDF/PlatformIO may include separate third-party licensing obligations. Never apply this repository's all-rights-reserved label to override upstream licenses.

No blanket claim that all source is original or assignable to 918 Technologies is made. Third-party software remains subject to its legal terms; no proprietary distribution license is asserted for it without verification.
